## Structure

Each channel is one telemetry stream from the spacecraft. Arrays have the shape `(time, features)`. Column 0 is the telemetry value, already scaled to roughly [-1, 1] by NASA. The other columns are one-hot flags for commands sent to the spacecraft. Train series are unlabelled and assumed nominal. Test series carry expert-labelled anomaly segments (inclusive `[start, end]`) of type *point* or *contextual*.

## Known caveats

- **Test-set scaling in the source.** Many channels reach exactly ±1.0 in *test* but not in train, which suggests NASA min-max scaled them with test-period ranges. We re-fit our own scalers on train rows only, but the source scaling cannot be undone.
- **Train is not guaranteed clean.** No labels exist for train, so robust (median/IQR) scaling is used to limit the influence of hidden anomalies.
- **Channel semantics are anonymised.** Prefixes (A, B, C, D, E, F, G, M, P, R, S, T) group related channels, but NASA did not publish what each measures.
