# Roadmap

Each phase ships as working, tested code. Every phase must pass `make check` and CI before
the next one starts.

| Phase | Scope | Exit criteria | Status |
|---|---|---|---|
| **1. Data foundation** | Verified download, label cleaning, quality validation, train-only scaling, windowing, reproducible prepare runs, data card, CI | 80 channels prepared from checksummed data; 90 tests; `mypy --strict` clean | ✅ done |
| **2. Evaluation harness + baselines** | Label-free thresholds; composite, event-wise and point-adjusted F1, detection delay, FP events per 1k steps, AUC-PR; bootstrap CIs; limit-check, robust z-score, Isolation Forest and random baselines; generated leaderboard ([BASELINES.md](BASELINES.md)) | Reproducible baseline scores on SMAP and MSL, with and without flagged channels ([ADR 0004](adr/0004-evaluation-protocol.md)) | ✅ done |
| **3. Deep detectors** | PyTorch LSTM forecaster (Telemanom-style) and bottlenecked Transformer autoencoder; causal EWMA scoring; deterministic per-channel training with parallel `--jobs`; MLflow tracking (optional); paired bootstrap comparisons ([ADR 0005](adr/0005-deep-detectors.md)) | Beat the baseline band (composite F1 ≈ 0.37–0.46) with non-overlapping 95% CIs on at least one spacecraft. **Outcome:** AUC-PR beats every baseline with paired significance (all channels and SMAP); 91/103 events found. Composite F1 0.524 (Transformer) is ahead but not significant, because static thresholds flood alarms. That gap moves to Phase 4 | ✅ done |
| **4. Decision layer** | EVT (peaks-over-threshold) calibration to surprise, fusion, hysteresis alarms, event builder with severity, type and per-detector evidence; Telemanom dynamic threshold and pruning as reference; streaming recalibration; global oracle; pre-registered ablations ([ADR 0006](adr/0006-decision-layer.md), [DECISION.md](DECISION.md)) | Composite F1 significantly above the best baseline on one spacecraft within ≤ 1 false event per 1k steps. **Outcome: not met** as pre-registered (primary ties the limit check, 1.30 false events per 1k). Diagnosis: a validation-to-test shift, visible without labels. Adaptive variants beat the limit check on SMAP (live post-hoc variant +0.148 [+0.047, +0.279], 0.23 false events per 1k), but are not confirmatory | ✅ done |
| **5. Explainability** | Verified model rebuild; onset; counterfactual LSTM rollout with commands actually sent and a calibrated band; Integrated Gradients attribution; grounded template narrative with a checker; optional grounded LLM rewording ([ADR 0007](adr/0007-explainability.md), [EXPLAINABILITY.md](EXPLAINABILITY.md)) | Explanation hit@3 reported; every narrative sentence traceable to a computed value. **Outcome:** 1,373/1,373 sentences grounded; hit@3 above chance (temporal 22% vs 5%, command 38% vs 9%); pre-registered deletion and band-coverage hypotheses not supported (diagnosed: mis-specified deletion test, data shift). Attribution revealed the LSTM ignores commands | ✅ done |
| **6. Health and operations** | Subsystem Health Index, RUL with uncertainty, FastAPI service, Streamlit operator console, feedback capture | Demo: replayed stream → explained alert → operator verdict stored | next |
| **7. Extensions** | Graph Deviation Network, command-aware forecaster (Phase 5 finding), adaptive counterfactual band, onboard int8 ONNX export with a size and latency report, ESA-ADB / OPS-SAT loaders with a **pre-registered confirmation** of the Phase 4 adaptive pipelines, drift monitoring and retraining | Stretch goals for the final pitch | planned |
